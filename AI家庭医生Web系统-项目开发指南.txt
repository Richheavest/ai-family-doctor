六、DAO层使用指南（后端开发必读）
================================================================================

  所有表DAO已封装完毕，直接引入即可使用，无需手写SQL。

  【引入方式】
    const userDao = require('./dao/userDao');
    const consultDao = require('./dao/consultDao');
    const familyDao = require('./dao/familyDao');
    const healthDao = require('./dao/healthDao');
    const roleDao = require('./dao/roleDao');
    const logDao = require('./dao/logDao');

  【通用方法（所有DAO通用）】
    findById(id)              → 按主键查单条
    findOne(conditions)       → 条件查单条 {字段: 值}
    find(conditions, options) → 条件查列表（支持分页/模糊/范围/排序）
    findWithPage(conditions, options) → 查列表+总数 {list, total, page, pageSize}
    count(conditions)         → 统计总数
    insert(data)              → 新增，返回自增ID
    updateById(id, data)      → 按主键更新
    update(conditions, data)  → 条件更新
    deleteById(id)            → 物理删除
    softDeleteById(id)        → 逻辑删除（仅t_consult_record、t_family_relation）
    query(sql, params)        → 自定义SQL查询

  【options参数说明】
    {
      page: 1,                // 页码（从1开始）
      pageSize: 20,           // 每页条数
      orderBy: 'create_time DESC',   // 排序
      likeConditions: { name: '张三' },    // 模糊搜索
      rangeConditions: { age: { min: 18, max: 60 } }  // 范围查询
    }

  【示例：开发一个健康档案接口】
    // 在 controller 中：
    const healthDao = require('../dao/healthDao');

    // 查某用户的体征数据（带分页+时间范围）
    const result = await healthDao.getSignsByUser(userId, {
      page: 1,
      pageSize: 20,
      startTime: '2026-01-01',
      endTime: '2026-06-30'
    });
    // → { list: [...], total: 15, page: 1, pageSize: 20 }


七、前端开发指南（前端开发必读）
================================================================================

  【新增一个页面步骤】

  1. 在 src/views/ 下创建 YourPage.vue
  2. 在 src/router/index.js 的 routes 数组中添加路由：
     {
       path: '/home/user/health',
       name: 'Health',
       component: () => import('@/views/HealthPage.vue'),
       meta: { title: '健康档案', role: [1] }   // role控制可访问的角色
     }
  3. 在对应主页侧边栏 menuItems 中添加菜单项
  4. 在 src/api/ 下新建对应的API文件（如 health.js）
  5. 调用API：import { xxxAPI } from '@/api/health'

  【Axios请求示例】
    import { getFamilyListAPI } from '@/api/family'

    // 直接调用，错误由拦截器自动弹窗
    const data = await getFamilyListAPI()
    // data 已经是 response.data.data（拦截器自动解包）

  【全局CSS类名（直接用）】
    .login-container     → 全屏居中背景
    .page-card           → 白色圆角卡片
    .home-layout         → 侧边栏+主区域布局
    .home-sidebar        → 深色侧边栏（220px宽）
    .home-main           → 主区域
    .home-header         → 顶部栏（60px高）
    .home-content        → 内容区

  【Pinia用户状态】
    import { useUserStore } from '@/store/user'
    const userStore = useUserStore()
    userStore.token       // JWT令牌
    userStore.userId      // 用户ID
    userStore.roleId      // 角色（1普通/2家人/3管理员）
    userStore.realName    // 真实姓名
    userStore.isAdmin     // 是否管理员
    userStore.logout()    // 退出登录

十、开发规范
================================================================================

  1. 后端新增接口遵循：router → controller → service → dao 四层调用
  2. 所有接口返回统一格式：{ code: 200, msg: 'xxx', data: {...} }
  3. 业务异常用 throw new AppError('ERROR_KEY') 抛出
  4. 错误码在 config/errorCode.js 中统一定义
  5. 前端页面使用 ElementPlus 组件，保持风格统一
  6. API请求统一用 src/api/ 下的封装函数，不要在组件中直接写axios
  7. Git提交代码前先 npm run build 确保无构建错误
  8. 中文注释，小驼峰命名变量，大驼峰命名组件
